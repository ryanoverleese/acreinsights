Will a corn field make it through the season?

Early-season signal against where the same probes ended up. 261 corn probes, 2026-05-29 to 2026-08-09.

A corn probe that starts the year at 90% or better has an 88% chance of still being above 60% in August.

Below 75% early, it is about 15%. There is very little in between — the curve turns hard somewhere around 75, and does not become dependable until 90.

Read this before you use the number.

This is all corn probes, not stub-only. Antenna type lives in Baserow probe_assignments, and the API token in signal_tracker.py and baserow_backup.py is revoked — every table returns 403. Tall antennas both start high and stay high, so they will be flattering the high end here. The true stub threshold is probably higher than 90.
